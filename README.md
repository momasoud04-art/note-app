# تطبيق الملاحظات (Note App)

مشروع دبلومة JavaScript – المدرسة. تطبيق ملاحظات بـ HTML و CSS و JavaScript.

**الموقع المنشور:** https://momasoud04-art.github.io/note-app/

## الميزات
- إضافة ملاحظة (عنوان اختياري + نص)
- حذف ملاحظة
- تثبيت/إلغاء تثبيت ملاحظة (قسم «المثبّتة» وقسم «الملاحظات»)
- الحفظ في localStorage فتبقى الملاحظات بعد إعادة التحميل
- تصميم متجاوب (375 / 768 / 1440 بكسل) بدون تمرير أفقي

## الملفات
- `index.html` – الهيكل
- `style.css` – التنسيق
- `script.js` – المنطق والتخزين
